# RepoLore.Cli 0.1.0-preview.1 (preview, no author signature)

First public preview of RepoLore: local, offline operational memory for developers and coding agents, stored as Markdown.

## Install

```text
dotnet new tool-manifest
dotnet tool install RepoLore.Cli --version 0.1.0-preview.1 --local
```

A .NET 10 SDK is needed to install and a .NET 10.0.x runtime to run. See the [user guide](../user-guide.md).

## What it is

`init`, `path`, `context`, `tree`, `checkpoint`, `history`, `restore`, `health-check` and `migrate`, with explicit local sessions, checkpoint history that restore can undo, and migration from the alpha scripts. Knowledge format version 1.

## Limits of this preview

- The package has no author signature. NuGet.org adds only its own repository signature. It is not an enterprise-ready or certified release, and it makes no guarantee about what external editors or agents do with content they read.
- CI runs on Windows, Linux and macOS. The networking-blocked run exists on Linux only, and there is no network-call trace.
- Unknown knowledge formats are refused. Migration is explicit.
