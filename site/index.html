RepoLore

Local, offline operational memory for developers and coding agents, stored as Markdown.

RepoLore keeps what a maintainer needs to know before changing an area of a repository as plain Markdown under _repolore/. The repolore command reads it, checks it and protects it with local checkpoints. It makes no network calls and sends no telemetry. Current version: __VERSION__.

Install

WithRun
macOS or Linux
curl -fsSL https://repolore.org/install.sh | sh
Windows (PowerShell)
irm https://repolore.org/install.ps1 | iex
Homebrew
brew install repolore-org/tap/repolore
winget
winget install repolore
Python (pipx, uv or pip)
pipx install repolore
Node.js (npm)
npm install -g repolore-cli
.NET (pinned per repository)
dotnet new tool-manifest
dotnet tool install RepoLore --version __VERSION__ --local

Every channel installs the same native executable, except .NET, which installs the same tool as a .NET tool. The install scripts check the file against the release's checksums before installing it.

Download

Systemx64arm64
Windows zip zip
macOS tar.gz tar.gz
Linux (glibc) tar.gz tar.gz

Verify a download against repolore-__VERSION__.sha256, for example with shasum -a 256 -c. The executables have no code signature: on macOS, a file downloaded with a browser is blocked until you allow it, so prefer the install script or Homebrew there. On Windows, SmartScreen may warn about the file.
